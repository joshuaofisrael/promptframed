Poster guide

How to turn ChatGPT art into a framed poster

You already have the picture. The rest is a file that can survive a wall, a page people can open, and a print shop that mails the paper. Prompt Framed does this for the Night Windows gallery. The same path works for one image or a series of ten.

Make a picture that still works in a room

Phone screens forgive a lot. A poster does not. The subject should read from across the room. Tiny captions, watermarks, and detail crushed into the outer edge get lost once the paper has a margin.

Portrait 2:3 is a natural poster shape. Moonlit Alpine Meadow and Moonlit Mediterranean Village are 1024 by 1536 pixels. That is honest for a smaller print, about 7 by 10 inches at 150 dots per inch. Bigger paper stretches those same pixels. For a large poster, export a higher-resolution file before you send it to the shop. Some later Night Windows pictures are wider. Match the paper to the file instead of forcing every piece into one crop.

Night scenes print darker than they look on a bright phone. If the sky is nearly black, lift the shadows a little so the ridge still separates on paper. Keep the warm windows. They are what the eye finds first.

Export a clean file

Save a PNG of the full picture and keep that file as the print master. The gallery pages use a smaller JPEG so the site stays fast. Do not upload a screenshot of a chat window. Crop away the interface.

  • Keep important shapes inside the image, not on the edge a frame can cover.
  • Check that windows, faces, and type are not warped.
  • Know the pixel size before you pick a poster size.

Sell the poster first, then the frame

Start with one product: a poster. People understand it, and it is the sentence in the caption. A framed print is the second product for the same picture, with its own shop link, once the frame style exists.

Print on demand means you do not buy a stack of posters in advance. When someone orders, the shop prints that one and mails it. Prompt Framed is set up for Printful. The piece page holds the button. The shop holds the payment. Until the shop link is real, the button stays on this site and does not pretend to charge anyone.

Give the picture its own page

The buy link in a caption should open a page about that picture. Show the image large, say what it is in a sentence or two, and put Buy Poster where a thumb can reach it. Keep Framed Print separate so the two products stay distinct.

The address does not change when you later connect the shop. Only the button’s destination changes, and that destination is the URL saved in products.json.

Write the caption so the link is the last thing

Instagram is the front door. Name the picture, give one line of mood, then the buy line. Every Night Windows piece page has a caption you can copy. It ends like this:

Want a poster? Buy at the link: https://moonlitwindows.com/pieces/moonlit-alpine-meadow.html

The link is the piece page. The piece page has the button.

Say what the picture is

If a picture may be made with ChatGPT or another image tool, say so where a visitor can find it without turning the gallery into a technical note. Prompt Framed keeps that sentence in the footer and on the About page. The pictures themselves are titled as pictures.
